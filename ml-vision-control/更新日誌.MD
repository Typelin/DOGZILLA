# 更新日誌 — DOGZILLA 數字視覺控制系統

## [v1.0.0] — 2026-03-08

### 專案概述
透過攝影機偵測手機螢幕上顯示的數字 (0-9)，辨識後控制 DOGZILLA 機器狗執行對應動作。

### 已實現功能

#### 數字偵測引擎 (`pc/digit_engine.py`)
- **白色四邊形偵測**：多閾值 (220/200/185) 搜尋畫面中的白色長方形區域（手機螢幕）
- **矩形相似度檢查**：三層驗證 — 對邊比例 >0.4、面積/最小外接矩形 >0.80、四角角度 65°-115°
- **透視校正**：使用 `approxPolyDP` 取得四邊形頂點 → `getPerspectiveTransform` 校正為正面視角
- **CNN 數字辨識**：11 類 CNN (0-9 + 背景)，ONNX 格式推論
- **單一螢幕單一數字**：每個偵測到的螢幕只保留最大前景輪廓，避免邊框雜訊
- **螢幕邊框可視化**：青色多邊形顯示偵測到的螢幕範圍
- **亮度過濾**：螢幕內部平均亮度 >195、標準差 <55，確保為白底

#### CNN 模型訓練 (`pc/train_cnn.py`)
- **混合訓練資料**：MNIST 60,000 張 + PIL 合成 15,000 張 + 背景 7,000 張 = 82,000 張
- **PIL 系統字體渲染**：使用 16 種 Windows 系統字體 (Arial, Calibri, Segoe UI, Verdana, Tahoma, Consolas 等)
- **資料增強**：隨機旋轉、透視變形、腐蝕/膨脹、高斯模糊、噪點
- **模型架構**：2 層卷積 (1→32→64) + 全連接 (64×7×7→128→11)
- **訓練結果**：15 輪，測試準確率 99.58%

#### PC 端即時偵測 (`pc/camera_detect.py`)
- 即時攝影機畫面 + 偵測結果顯示
- 4 幀多數決投票穩定
- Debug 模式 (閾值/二值化視圖)
- 鍵盤控制 (q/d/l/+/-/space)

#### Pi 端部署控制 (`deploy_pi/digit_control.py`)
- **All-in-One 單檔部署**：只需 `digit_control.py` + `digit_cnn.onnx` 兩個檔案
- **數字 → 動作對應** (參考 test_action 系列及官方 API)：

  | 數字 | 動作 | API 呼叫 |
  |:---:|------|----------|
  | 0 | 重置歸位 | `action(255)` |
  | 1 | 前進 | `forward(80)` 2秒 |
  | 2 | 後退 | `back(80)` 2秒 |
  | 3 | 向左轉 | `turnleft(80)` 2秒 |
  | 4 | 向右轉 | `turnright(80)` 2秒 |
  | 5 | 坐下 | `action(12)` 3秒 |
  | 6 | 伸懶腰 | `action(14)` 4秒 |
  | 7 | 招手 | `action(13)` 4秒 |
  | 8 | 握手 | `action(19)` 4秒 |
  | 9 | 轉圈 | `action(4)` 5秒 |

- **連續幀防彈跳**：必須連續 15 幀偵測到同一數字才觸發（中斷即歸零）
- **冷卻機制**：觸發後 5 秒冷卻期，防止重複觸發
- **重複觸發保護**：同一數字連續觸發需中間有空幀
- **初始化設定**：自動設定 `pace("normal")` + `translation('z', 108)` 標準站姿
- **模擬模式**：`--no-dog` 可在無機器狗環境下測試辨識
- **無頭模式**：`--headless` 無畫面模式

### 專案結構
```
ml-vision-control/
├── pc/                     # PC 端開發與訓練
│   ├── digit_engine.py     # 數字偵測引擎 (v7)
│   ├── camera_detect.py    # 即時攝影機偵測 GUI
│   └── train_cnn.py        # CNN 訓練腳本
├── deploy_pi/              # Pi 部署包 (這兩個檔案直接複製到 Pi)
│   ├── digit_control.py    # All-in-One 控制腳本
│   └── digit_cnn.onnx      # CNN 模型 (~1.8MB)
├── models/                 # 訓練產出模型
│   └── digit_cnn.onnx
├── data/                   # 訓練資料 (MNIST)
│   └── MNIST/raw/
└── 更新日誌.MD
```

### Pi 部署方式
```bash
# 1. 複製到 Pi
scp deploy_pi/digit_control.py deploy_pi/digit_cnn.onnx pi@<IP>:~/Desktop/ml-vision-control/

# 2. Pi 上安裝依賴 (首次)
pip install onnxruntime

# 3. 停止背景服務 & 執行
sudo pkill -f app_dogzilla.py
python3 digit_control.py
```

### 技術參數
- **Python**: 3.11 (Pi) / 3.12 (PC)
- **CNN 推論**: onnxruntime (CPUExecutionProvider)
- **影像處理**: OpenCV 4.x
- **移動速度**: 80, 持續 2 秒
- **旋轉速度**: 80, 持續 2 秒
- **站姿高度**: 108
- **步頻模式**: normal

### 已知限制
- 數字 7 偶爾被誤判為 1（外觀相似）
- 需要白底黑字的清晰螢幕顯示
- 光線過暗或過度反光可能影響螢幕偵測
